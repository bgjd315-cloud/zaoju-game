# 造句積木工坊

給國小二到四年級的造詞、造句互動遊戲，配合康軒版國語二上到四下各課。

- 二、三、四年級每一課都有「造詞」與「造句」兩種練習。
- 二、三年級畫面附注音（可關閉），以國字為主、注音為輔。
- 三、四年級有加長的課文詞彙例句與「美句示範」，改病句的句型附「病句＋改正」對照。
- 自己寫句子時有檢查清單與「美句加分」（比喻、疊字、感官、心情、時間地點），不需要網路 AI 也能使用。
- 進度、作品集都存在瀏覽器裡，不會上傳。

## 使用方式

直接用瀏覽器打開 `index.html`，或開啟 GitHub Pages 後用網址遊玩。

## 檔案

- `index.html`：遊戲本體（單一檔案）
- `img/`：情境插圖、角色頭像與字型
- `image-prompts.html`：插圖的生圖提示清單

## 說明

- 題目與例句是依課文情境另外撰寫的練習內容，不是課本原文；課名與課次對應康軒版國語課本。
- 插圖為 AI 生成。
- 字型取自「字嗨注音標楷」（Bpmf Zihi KaiStd，But Ko，https://github.com/ButTaiwan/bpmfvs ），漢字部分 CC BY 4.0、注音部分 SIL OFL 1.1。本專案只取用到的字做成子集，並依授權改名為 ZaojuZhuyin（附注音）與 ZaojuKai（不附注音）。授權全文見 `img/FONT-LICENSE-ZihiKaiStd.txt`。
