# 造句積木工坊

給國小二到六年級的造詞、造句互動遊戲，配合康軒版國語二上到六下各課。

- 二到四年級：`index.html`
- 五、六年級：`high.html`（另有成語典故館與修辭工坊）

- 二、三、四年級每一課都有「造詞」與「造句」兩種練習。
- 二、三年級畫面附注音（可關閉），以國字為主、注音為輔。
- 三、四年級有加長的課文詞彙例句與「美句示範」，改病句的句型附「病句＋改正」對照。
- 五、六年級每課有抽象而有美感的課文詞彙、依「語文讀寫」設計的句子精修（含多重複句與寫作技巧），並有成語典故館（135 個成語：讀典故、懂寓意、判斷情境、用成語造句）與修辭工坊（譬喻、摹寫、轉化、引用、層遞、設問、排比、映襯）。
- 寫作工坊（從句子走到段落）：三、四年級各 12 個段落任務、五年級每課一個寫作任務（24 個，對應各課「語文讀寫」的寫作策略：總結法、對照比較、圖表轉文字、事實與觀點、理由與例證、遠景與特寫、心情轉折……），依「讀範文・拆段落 → 有提示地寫 → 自己寫一段」逐步撤除提示，寫完用五個問題自我檢查（語意清楚、內容具體、組織連貫、想法感受、自己修改）。
- 自己寫句子時有檢查清單與「寫作小提示」（比喻、疊字、感官、心情、時間地點；只是提示，不是分數），不需要網路 AI 也能使用。
- 進度、作品集都存在瀏覽器裡，不會上傳。

## 使用方式

直接用瀏覽器打開 `index.html`，或開啟 GitHub Pages 後用網址遊玩。

## 檔案

- `index.html`：二到四年級遊戲
- `high.html`：五、六年級遊戲
- `img/`：情境插圖、角色頭像與字型
- `image-prompts.html`：插圖的生圖提示清單
